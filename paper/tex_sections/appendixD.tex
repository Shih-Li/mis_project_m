\section{Reproducibility and Data Availability}
\label{app:reproducibility}

Code and materials used in this thesis are organised across two GitHub repositories.

\begin{enumerate}
\item \textbf{MIS thesis repository:}
\url{https://github.com/Shih-Li/mis_project_m}.
This repository contains the simulation scripts and functions, analysis pipelines, generated tables and figures, and the \LaTeX{} source for the thesis.

\item \textbf{Empirical replication repository:}
\url{https://github.com/Shih-Li/ra2026-replication}.
This repository contains the paper-specific R replications for the ten empirical studies and the cross-study MIS audit. Original study data and replication materials should be obtained from the sources documented in the corresponding paper-specific sub-README files.
\end{enumerate}
